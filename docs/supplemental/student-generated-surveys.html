Typically, Dr. Gilmore would download the data using code. Here he manually downloaded the file and saved it as a CSV under private/csv.

## Import data

Dr. Gilmore created a Google sheet to keep track of the data.

::: {.callout-note}
## Manual vs. automatic downloading

Typically, Dr. Gilmore would download the data using code.
Here he manually downloaded the file and saved it as a CSV under `private/csv`.

This avoids issues related to Google authentication, but requires an additional manual step.

:::

We read the data file into a data frame.

```{r}
surveys_df <- readr::read_csv("../private/csv/psych-490.007-2026-fall-surveys - Sheet1.csv", show_col_types = FALSE)
```

## Summarize

```{r}
summary(surveys_df)
```

There were *n*=`{r} dim(surveys_df)[1]` submissions.

*N*=`{r} sum(is.na(surveys_df$edit_url))` submissions did *not* include an edit link. Check [below](#editor-links) to see if you provided that link.

*N*=`{r} sum(is.na(surveys_df$response_url) & surveys_df$canvas_submission == "yes")` students submitted write-ups to Canvas but did not send the edit link to the survey to Dr. Gilmore.

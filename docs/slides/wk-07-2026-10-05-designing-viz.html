Choose your dataset

  • You might try the data() command to see what is available inside R.
  • If you want to use the data in nflreadr, you will need to add library(nflreadr) to your R code in your Setup section.

Load your dataset

  • Some datasets are available to you without doing anything special, e.g., mtcars.
  • Some datasets, e.g., diamonds, are available when you load the R package that contains it, using library(ggplot2)
  • If you use the nflreadr package, you will need to use nflreadr::load_ function. See the tutorial.

Explain why

A best practice to adopt is to explain your choices. So, if you use a dataset built in to R, say that’s what you did. If you choose a package that must be loaded from another source, explain that.

Figure numbering is optional

Note that the code chunk on the previous page added #| label: fig-01 before the actual code.

This tells Quarto to add a figure number automatically.

If you get this to work, bravo!

The main benefit is that you can now write @fig-01 in your text, and Quarto will create a link to the figure.

So, your Figure 1 section could look like the following.

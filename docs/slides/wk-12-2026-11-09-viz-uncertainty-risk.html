Communicating uncertainty

Frequencies vs. probabilities

  • p = .01 vs. 1% chance vs. 1 chance in 100
  • p = .10 vs. 10% chance vs. 10 chances in 100
  • p = .40 vs. 40% chance vs. 40 chances in 100

Example closer to home

  • What’s the probability that Penn State football ends up with a winning (regular) season?
  • Current record (2026-11-02) is 4-4; 4 games left.
  • So, need to win 3/4 to end up 7-5.
library(ggplot2)
library(dplyr)
library(ggbeeswarm)
sim_40 <- rbinom(n = 100, size = 4, prob = .4)
sim_60 <- rbinom(n = 100, size = 4, prob = .6)
psu_proj_df <- data.frame(wins = c(sim_40, sim_60), 
                          p_win = rep(c(40, 60), 
                                      each = 100))
  • Binomial distribution models binary outcomes
  • In the code above, size = 4 is the number of games
  • prob = .4 and prob = .6 is the probability of winning each game
  • We simulate running this experiment n = 100 times
  • The data are the number of expected wins

Point estimates

Types

  • Mean: center of mass
  • Median: middle-most
  • Mode: peak value(s)
  • Why use them?

Occam’s razor

  • One number < n numbers, sometimes <<<

Another reason

  • Point estimates are “models” of the data
  • Good models can be used to make predictions

“All models are wrong; Some are useful.”

– attributed to George Box

Considerations

  • When is a point estimate (mean, median, mode) a “useful” model?
  • Is the distribution unimodal?
  • Is it bell-shaped (e.g., normal) or symmetric?
  • Do the mean or median capture the peak of the data? Are they representative?
  • How do I answer these questions?

When (else) it matters…

  • When the sample consists of two heterogeneous groups with different means!
  • Let’s create two random normal datasets with different means, 0 and 2
  • The standard deviation is the same
  • Then we combine and plot them as one
p1 <- rnorm(100, 0, 1)
p2 <- rnorm(100, 2, 1)
p_both <- data.frame(value = c(p1, p2), 
                     source = rep(c("p1", "p2"), 
                                  each = 100))
                    
p_both |>
  ggplot() +
  aes(x = value) +
  geom_histogram(bins = 20)

Can you see the two distributions?

Does the histogram clearly show them?

Commentary

  • Plotting the data is no panacea2
  • Some plot types don’t even hint that there might be two different distributions
  • Often, we don’t know that there is even a possibility that there are two groups
  • Here’s an extreme example where plotting shows the pattern…
p1 <- rnorm(100, -2, 1)
p2 <- rnorm(100, 2, 1)
p_both <- data.frame(value = c(p1, p2), 
                     source = rep(c("p1", "p2"), 
                                  each = 100))

x_mean <- mean(p_both$value)
x_med <- median(p_both$value)
p_both |>
  ggplot() +
  aes(x = value) +
  geom_histogram(bins = 20) +
  annotate("text",
           x = 0,
           y = 30,
           label = paste0("Mean = ", 
                          format(x_mean, digits = 3))) + 
  annotate("text", 
           x = 0, 
           y = 25, 
           label = paste0("Median = ",
                          format(x_med, digits = 3)))

Boxplot anatomy

  • Bar, box & whiskers (geom_boxplot())
    • Bar: median
    • Box: middle 50% (25th…75th percentile)
    • Whiskers: middle 90% (5th…95th percentile)

Histograms, violin plot, boxplots

  • Don’t show raw data points
    • Unless we add them
  • Do show shape, symmetry
  • Do show whether mean ~ median are representative of “typical” values
  • May show whether distribution is a mix of subgroups

Wrap up

Main points

  • Discrete variables
    • Outcome/event counts > probabilities or likelihoods
  • Continuous variables
    • Raw data +
    • Alpha, jitter, beeswarm

Main points

  • Continuous
    • Histogram, violin, boxplot or combinations

Main points

  • Point estimates
    • Mean, median, mode
  • Simple model of a dataset
    • All models are wrong, some are useful
    • Think about when point estimates are useful
  • Plot your data!

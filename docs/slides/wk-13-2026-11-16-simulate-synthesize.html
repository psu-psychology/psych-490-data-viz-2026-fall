What do we think we know?

  • RT continuous
    • Bounded from below: \((0, RT_{max}]\)1
    • Or is there an \(RT_{min}\)?
  • \(RT_{congruent}<RT_{incongruent}\)
  • \(Accuracy_{congruent}>Accuracy_{incongruent}\)

In Bayesian statistics, these might be called priors.

Specify a model (in words)

  • RT is equal to the time required to name a word’s color
    • Plus more time if the color is…incongruent
    • Plus random error

Specify a model (quantitatively)

  • Time to name a word’s color: \(RT_{name-a-color}\)
  • Extra time if the color is incongruent: \(t_{incongruent}\)
  • Random error: \(N(0, sd)\)2

\[ RT=RT_{name-a-color}+t_{incongruent}+N(0, sd)\]

More (simplifying) assumptions

  • \(RT_{name-a-color}\) is the same for all colors
  • \(RT_{name-a-color}\) doesn’t change across the experiment
  • \(t_{incongruent}\) doesn’t change across the experiment

How many congruent vs. incongruent trials?

  • Let’s specify 3/4 trials will be congruent
  • Make attending to color of text more salient
congruency <- rep(c("cong", "cong", "cong", "incong"), 25)
cong_incong <- sample(x = congruency, replace = FALSE)
stroop_df$cong_incong <- cong_incong

On to our model

\[ RT=RT_{name-a-color}+t_{incongruent}+N(0, sd)\]

rt_name_a_color <- 500 # milliseconds
t_incong <- 20
sd_rt <- 10

stroop_df <- stroop_df |>
  mutate(rt = rt_name_a_color + 
           if_else(cong_incong == "incong", t_incong, 0) +
           rnorm(n = 100, sd = sd_rt))

Why should we care?

  • Simulate your design before you collect data

  • Build your data viz pipeline in advance
  • Specify your assumptions, check them
  • Simulation cheaper than running a study678

Intro to ggplot

What is it?

  • R package that implements Cleveland’s “grammar of graphics”
    • Written by Hadley Wickham, CTO of Posit.co
  • Map data to figure components
    • Position
    • Color, shape, size
  • Add layers to figures

Why ‘code’ your figures?

  • Easier to reproduce
  • Easier to edit
  • Try out different styles, pick the best
  • Be kind to your future (forgetful) self
  • Makes programming more fun

Installing ggplot

  • Open RStudio
  • Enter the following in your R console
install.packages("ggplot2")

Let’s make some data

Code 
days <- factor(
  c("sun", "mon", "tue", "wed", "thu", "fri", "sat"),
  levels = c("sun", "mon", "tue", "wed", "thu", "fri", "sat"),
  ordered = TRUE
)
meals <- factor(
  c("breakfast", "lunch", "dinner", "snack", "dessert"),
  levels = c("breakfast", "lunch", "snack", "dinner", "dessert"),
  ordered = TRUE
)
meal_days <- rep(days, each = length(meals))
weekly_meals <- rep(meals, 7)

my_meals <- data.frame(day_of_wk = meal_days, 
                       meal = weekly_meals)

Nominal data often require processing before plotting

This is most often a count of the number of instances per category. It could be the relative proportion, but this is calculated from the number of instances.

Figure 1.1

  • Add a fill aesthetic to fill the bars with colors
Code 
my_meals |>
  ggplot() +
  aes(x = ate_skipped, fill = ate_skipped) +
  geom_bar()
  • If we fill from ate_skipped
    • ggplot will map a color to each distinct value of ate_skipped
    • and add a legend, so we know what the colors represent

Basic ggplot components

  • A data frame
  • Function call to ggplot()
  • Add layers to plot with + operator
  • Add aesthetics (mappings between data and graphic elements) using aes() with x (and often y) mappings
  • A geom_ layer

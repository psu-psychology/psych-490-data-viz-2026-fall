## Summarizing figures

### Continuous data

A best practice is to generate summary figures for all the variables in your dataset.
What should the figures summarize, or said in the language of *ggplot*, what `geom_` should we  use? Histograms (`geom_histogram()`), boxplots (`geom_boxplot()`), and violin (`geom_violin()`) plots are great for continuous data.

The following code chunk provides these for `carat` and `price`.

::: {#fig-summary-figures-carat-price}

````{r}
ggplot(data = diamonds) +
  aes(x = carat) +
  geom_histogram()
  
ggplot(data = diamonds) +
  aes(x = carat, y = "") +
  geom_violin() +
  geom_boxplot(alpha = .4) +
  ylab("")
````

Code to generate a histogram and combined boxplot/violin plot of the `carat` variable.

With those preliminaries finished, we can now use these libraries to sort the diamonds `color` data for our summary figure.

Here is the code to add to your Quarto document.

::: {#fig-histogram-color-sorted-dplyr-forcats}

````{r}
diamonds |>
  mutate(color_ct = fct_infreq(color)) |>
                                        
  ggplot() +
  aes(x = color_ct) +
  geom_histogram(stat = "count")

````

Code to render a sorted histogram/barplot of the `color` variable.
:::

Let's unpack what's happening here.
First, we give `ggplot2` input using a new command, the pipe (`|>`).
Think of the pipe as passing data to the next step.
Next, the `mutate()` function creates a new variable called `color_ct`, short for color count.
The value of `color_ct` comes from `fct_infreq(color)`, a function in the `forcats` package.
This package has all kinds of useful tools for manipulating factors, both ordered and unordered discrete variable.
Learn more about it [here](https://forcats.tidyverse.org/index.html).
The `mutate()` command creates a new variable called `color_ct` using `fct_infreq(color)` and adds it to the dataset.
We then pipe/pass this augmented dataset to ggplot, and the rest should be familiar to you already.

```{r}

  ggplot() +
  aes(x = color_ct) +                     #<3>

```

2. Use `mutate()` from dplyr and `fct_infreq()` from forcats to create a new variable called `color_ct`.
3. Use the new `color_ct` variable to make the histogram.

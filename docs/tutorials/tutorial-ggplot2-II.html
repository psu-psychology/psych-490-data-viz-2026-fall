## Good habits

One of the first things data analysts should do when we get our hands on a new dataset is answer some basic questions about it, specifically the following:

- How many cases (data points) are in the dataset?
- How many variables?
- Which variables are nominal, which are ordinal, and which are continuous?

R makes it easy to answeer these questions for us.
We use the `summary()` and `dim()` (dimension) commands.

## Summarizing figures

A best practice is to generate summary figures for all the variables in your dataset.
What should the figures summarize, or said in the language of *ggplot*, what `geom_` should we  use? Histograms (`geom_histogram()`), boxplots (`geom_boxplot()`), and violin (`geom_violin()`) plots are great for continuous data, but what about nominal (ordered or unordered) data?

The following code chunk provides these for `carat` and `price`.

::: {#fig-summary-figures-carat-price}

````{r}
ggplot(data = diamonds) +
  aes(x = carat) +
  geom_histogram()
  
ggplot(data = diamonds) +
  aes(x = carat, y = "") +
  geom_violin() +
  geom_boxplot(alpha = .4) +
  ylab("")
````

Code to generate a histogram and combined boxplot/violin plot of the `carat` variable.
:::

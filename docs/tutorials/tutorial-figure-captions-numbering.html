## Setup

```{r}
library(ggplot2)
```

## Figure captions

There are several ways to add captions to your Quarto figures depending on how the figures are generated.

### R code chunk

If you create a figure using an R code chunk, you can add a caption by using the `fig-caption` argument in the code chunk options. See @fig-add-caption-to-r-chunk.

::: {#fig-add-caption-to-r-chunk}

````{r}
#| label: fig-my-plot
#| fig-cap: "This is my plot. I hope that you like it."

x_random <- rnorm(n = 100)
random_df <- data.frame(x = x_random)

random_df |>
  ggplot(aes(x = x)) +
  geom_histogram() +
  labs(title = "Histogram of Random Data") + 
  theme_minimal()
````

This code shows how to add parameters to an R code chunk. The parameters are preceded by `#|`. 
The parameter values are specified as key-value pairs.
The key is the label before the colon `:`, and the value is what follows the colon
We need to label figures using `#| label: fig-<name>`, where the figure name is specified as `fig-<name>`; here it is `my-plot`.
This makes sure that your Quarto document assigns a unique name to your figure.
We also need a `#| fig-cap:` parameter (cap is short for caption) to add a caption.
:::

The figure rendered by @fig-add-caption-to-r-chunk is as follows:

```{r}
#| label: fig-my-plot-rendered
#| fig-cap: "This is my plot. I hope that you like it."

x_random <- rnorm(n = 100)
random_df <- data.frame(x = x_random)

random_df |>
  ggplot(aes(x = x)) +
  geom_histogram() +
  labs(title = "Histogram of Random Data") + 
  theme_minimal()
```

::: {.callout-note}
## Titles can coexist with captions.

We can make figures with titles using `labs(title = "Histogram of Random Data")` or the `ggtitle()` function.
The same figure can have a caption added using `fig-cap: "This is a caption"` in the chunk options.
:::

About

This page documents some activities related to the visualization of National Football League data using the nflreadr package.

Install the package

In your RStudio R console, install the nflreadr package as follows:

install.packages("nflreadr")

Get ready

  1. Create a new Quarto project.

  2. Add About and Setup sections.

In the Setup section, add a code chunk to bring the libraries we’re going to use into our workspace.

library(ggplot2)
library(nflreadr)

Explore the package

Until last week, I’d never played with this package. So, I’m still learning the ins and outs.

One good command to use in this situation is help(). You can use it with a package or with a function.

help("nflreadr")

For this package (and datasets), that wasn’t very helpful, but it did point to this site: https://nflreadr.nflverse.com. That was somewhat more useful.

Ultimately, I found myself using RStudio’s tab-complete option to find a dataset that seemed like a good place to start. See Figure 1.

Multivariate plots

Making univariate plots is usually just the first phase of exploring a dataset. The real fun starts when you use multiple variables to try to see relationships between variables.

The figures below introduce some multivariate plots some new tools that can make the data patterns easier to see.

Faceting 5.0

nfl_sched |>
  ggplot() +
  aes(x = total) +
  geom_histogram() +    
1  facet_wrap(~season)
1
Creates a faceted figure with a histogram for each of the values in season. 
`stat_bin()` using `bins = 30`. Pick better value `binwidth`.

Scatterplot 6.0

nfl_sched |>
  ggplot() +
  aes(x = home_score, y = away_score) +
  geom_point()   
Warning: Removed 225 rows containing missing values or values outside the scale range
(`geom_point()`).

Let’s try making the points more visible by adjusting the alpha parameter.

Scatterplot 6.1

nfl_sched |>
  ggplot() +
  aes(x = home_score, y = away_score) +
1  geom_point(alpha = 0.25)
1
An alpha of 0.25 means that the darkest shade is assigned to a point where there are 4 (e.g., \(1/\alpha\)) identical points , and the lightest shade is assigned to a point where there are 0 identical points.
NoteExperiment!

I tried a number of different alpha values.

The one in Figure 9 was not my favorite. What value do you prefer?

Scatterplot 6.2

nfl_sched |>
  ggplot() +
  aes(x = home_score, y = away_score) +
1  geom_point(alpha = 0.05) +
2  geom_smooth(method = "lm", se = FALSE)
1
I found that alpha= 0.05 worked reasonably well.
2
We can add a best-fitting line to the point data using geom_smooth(). By setting method="lm" and se=FALSE we fit a linear regression line to the data. 
`geom_smooth()` using formula = 'y ~ x'

## Multivariate plots

Making univariate plots is usually just the first phase of exploring a dataset.
The real fun starts when you use multiple variables to try to see relationships between variables.

The figures below introduce some multivariate plots some new tools that can make the data patterns easier to see.

### Faceting 5.0

```{r}
#| label: fig-faceting-5.0
nfl_sched |>
  ggplot() +
  aes(x = total) +
  geom_histogram() +    
  facet_wrap(~season) #<1>
```

1. Creates a faceted figure with a histogram for each of the values in `season`.

### Scatterplot 6.0

```{r}
#| label: fig-scatterplot-6.0
nfl_sched |>
  ggplot() +
  aes(x = home_score, y = away_score) +
  geom_point()   
```

Let's try making the points more visible by adjusting the alpha parameter.

### Scatterplot 6.1

```{r}
#| label: fig-scatterplot-6.1
nfl_sched |>
  ggplot() +
  aes(x = home_score, y = away_score) +
  geom_point(alpha = 0.25)  #<1>
```

1. An `alpha` of 0.25 means that the darkest shade is assigned to a point where there are 4 (e.g., $1/\alpha$) identical points , and the lightest shade is assigned to a point where there are 0 identical points.

::: {.callout-note}
## Experiment!

I tried a number of different `alpha` values.

The one in @fig-scatterplot-6.1 was not my favorite.
What value do you prefer?

:::

### Scatterplot 6.2

```{r}
#| label: fig-scatterplot-6.2
nfl_sched |>
  ggplot() +
  aes(x = home_score, y = away_score) +
  geom_point(alpha = 0.05) +             #<1>
  geom_smooth(method = "lm", se = FALSE) #<2>
```

1. I found that `alpha`= 0.05 worked reasonably well.
2. We can add a best-fitting line to the point data using `geom_smooth()`. By setting `method="lm"` and `se=FALSE` we fit a linear regression line to the data.

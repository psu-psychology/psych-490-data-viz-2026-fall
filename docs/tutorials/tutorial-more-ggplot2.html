1 About

This tutorial shows how to use additional commands in ggplot2 to customize figures.

I recommend that you create your own RStudio project with a new Quarto document to work through this tutorial.

2 Setup

Code 
library(ggplot2)
library(dplyr)

Attaching package: 'dplyr'
The following objects are masked from 'package:stats':

    filter, lag
The following objects are masked from 'package:base':

    intersect, setdiff, setequal, union

3 Acquire data

Let’s make some continuous data that have different degrees of relatedness.

n_pts = 600
x <- rnorm(n = n_pts, mean = 0, sd = 1)
y_25 <- x + rnorm(n_pts, mean = 0, sd = 0.25)
y_50 <- x + rnorm(n_pts, mean = 0, sd = 0.50)
y_75 <- x + rnorm(n_pts, mean = 0, sd = 0.75)
y_100 <- x + rnorm(n_pts, mean = 0, sd = 1)
y_125 <- x + rnorm(n_pts, mean = 0, sd = 1.25)
y_150 <- x + rnorm(n_pts, mean = 0, sd = 1.50)

df <- data.frame(x = rep(x, 6), 
                 y = c(y_25, y_50, y_75, y_100, y_125, y_150), 
                 noise = c(.25, .50, .75, 1.00, 1.25, 1.50), 
                 each = n_pts)
ImportantChange any variable you like

One powerful way to learn a new skill is to take sample code, alter it, and see what happens. Here, you could change the n_pts variable to see how the figures look with different number of points.

4 Visualize

4.1 Basic scatterplot

In Figure 1, I filter the bigger dataset using the filter(noise == 0.25) command. This selects the subset where the noise is 0.25.

NoteTroubleshooting

Make sure that your Quarto document’s Setup chunk has library(dplyr) in it. Alternatively, you could change the filter(noise == 0.25) line to dplyr::filter(noise == 0.25). This tells R to find and use dplyr even if you haven’t run library(dplyr) in your Quarto document.

If this fails, then you may need to install dplyr. In your R console, outside of your Quarto document, run install.packages("dplyr"). Then go back and render your Quarto document.

Think of the problem this way. Let’s say that your friend says “I have to call Mike.” But you know lots of Mike’s, so unless it’s obvious from context which Mike you’re talking about, things could go sideways. By telling R library(dplyr), we’re saying that we’re talking about filter() from the dplyr package, not some other filter() command.

df |>
  filter(noise == .25) |>
  ggplot() +
  aes(x, y) +
  geom_point()

4.2 Adjust alpha

In Figure 2 I try reducing clutter by adjusting alpha. The alpha parameter controls the saturation (intensity) of the dots based on how many points overlap. Lower values of alpha mean that more points have to overlap for that point to appear darker or more saturated. Notice that the alpha parameter belongs with geom_point(). If we had other layers, say lines or annotations, these could have their own alpha levels.

Here I tried alpha = 0.3.

df |>
  filter(noise == .25) |>
  ggplot() +
  aes(x, y) +
  geom_point(alpha = .3)

5 Change theme

In Figure 3 I eliminate the gray background, by adding a theme. There are many ggplot2 themes, but theme_classic() is a decent place to start.

df |>
  filter(noise == .25) |>
  ggplot() +
  aes(x, y) +
  geom_point(alpha = .3) +
  theme_classic()

6 Add labels

In Figure 4, I keep the previous changes and add some labels using labs(), short for labels. Notice that the labs() function has a parameter for title, subtitle, and caption.

df |>
  filter(noise == .25) |>
  ggplot() +
  aes(x, y) +
  geom_point(alpha = .3) +
  theme_classic() +
  labs(title = "A scatter plot with random data.", subtitle= "y = x + N(0, .25).", caption = "The data show an expected strong linear relationship.")

6.1 Change text size

The text is small. In Figure 5, I adjust it with another theme() command.

df |>
  filter(noise == .25) |>
  ggplot() +
  aes(x, y) +
  geom_point(alpha = .3) +
  theme_classic() +
  labs(title = "A scatter plot with random data.", subtitle= "y = x + N(0, .25).", caption = "The data show an expected strong linear relationship.") +
  theme(title = element_text(size = 14))

Read the help document about the labs() command to learn more. Enter help("labs") into your R console.

7 Add best-fitting line

In Figure 6 we add a best-fitting line using geom_smooth(method = "lm").

df |>
  filter(noise == .25) |>
  ggplot() +
  aes(x, y) +
  geom_point(alpha = .3) +
  geom_smooth(method = "lm") +
  theme_classic() +
  labs(title = "A scatter plot with random data and a best-fitting line.",
       subtitle = "y = x + N(0, .25).",
       caption = "The data show an expected strong linear relationship.") +
  theme(title = element_text(size = 14))
`geom_smooth()` using formula = 'y ~ x'

8 Add annotation

In Figure 7 we add an annotations featuring the the correlation (r value) using annotate().

xy_corr <- with(df, cor.test(x, y))

  labs(title = "A scatter plot with random data and a best-fitting line.",

  annotate("text",
           x = -2,
           y = 3,
           label = "r = .89") +
  theme(title = element_text(size = 14))
`geom_smooth()` using formula = 'y ~ x'

8.1 Grab correlation

Add an annotation with the correlation using annotate(), but grab the correlation from a variable.

xy_corr <- with(df, cor.test(x, y))

8.3 Extend annotation

Add a p value and degrees of freedom to the annotation.

df_25 <- filter(df, noise == .25)

9 Facets

Let’s take the gist of Figure 9 and make a plot with multiple facets based on the amount of random noise added to y.

df_categorical_noise <- df |>
  mutate(noise_cat = ordered(noise))

df_categorical_noise |>
  ggplot() +
  aes(x, y) +
  geom_point(alpha = .1) +
  geom_smooth(method = "lm") +
  facet_wrap(facets = ~ noise_cat, ncol = 3) +
  theme_classic() +
  labs(title = "A scatter plot with random data and a best-fitting line at various levels of random noise.") +
  theme(title = element_text(size = 14))
`geom_smooth()` using formula = 'y ~ x'

10 Assigning names

In the next series of figures, we’ll take advantage of a cool feature of the ggplot2 syntax: Assigning figures to a variable. This can make the process of exploring different figure options much easier.

So, in Figure 13 below we give a very basic plot a name: p.

p <- df |>
  filter(noise == .25) |>
  ggplot() +
  aes(x, y) +
  geom_point()

p

Now, we can “add” new layers or themese to the base figure using the syntax indicated below.

10.1 Add a layer

p + theme_classic()

p_classic <- p + theme_classic()

10.2 Add a line

Figure 15 adds a smooth, best-fitting line to Figure 14. Note that in the previous code gave Figure 14 the name p_classic. This let’s us “add” the geom_smooth() to p_classic as indicated below.

p_classic + geom_smooth(method = "lm")
`geom_smooth()` using formula = 'y ~ x'

10.3 Dark theme

We can use this syntax to explore the space of features we want for our plot. Figure 16 tries theme_dark().

p + theme_dark() + geom_smooth(method = "lm")
`geom_smooth()` using formula = 'y ~ x'

10.4 Light theme

Figure 17 tries theme_light().

p + theme_light() + geom_smooth(method = "lm")
`geom_smooth()` using formula = 'y ~ x'

## Assigning names

In the next series of figures, we'll take advantage of a cool feature of the *ggplot2* syntax: Assigning figures to a variable.
This can make the process of exploring different figure options much easier.

So, in @fig-1.0 below we give a very basic plot a name: `p`.

```{r}
#| label: fig-1.0
#| echo: true
#| code-fold: false

p <- df |>
  filter(noise == .25) |>
  ggplot() +
  aes(x, y) +
  geom_point()

p
```

Now, we can "add" new layers or themese to the base figure using the syntax indicated below.

### Add a layer

```{r}
#| label: fig-1.1
#| echo: true
#| code-fold: false
p + theme_classic()

p_classic <- p + theme_classic()
```

### Add a line

@fig-1.2 adds a smooth, best-fitting line to @fig-1.1.
Note that in the previous code gave @fig-1.1 the name `p_classic`.
This let's us "add" the `geom_smooth()` to `p_classic` as indicated below.

```{r}
#| label: fig-1.2
#| echo: true
#| code-fold: false
p_classic + geom_smooth(method = "lm")
```

### Dark theme

We can use this syntax to explore the space of features we want for our plot.
@fig-1.3 tries `theme_dark()`.

```{r}
#| label: fig-1.3
#| echo: true
#| code-fold: false
p + theme_dark() + geom_smooth(method = "lm")
```

@fig-1.4 tries `theme_light()`.
